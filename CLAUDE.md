# REI — инструкции для работы в репозитории

- Читай `docs/Architecture.md`, `docs/Roadmap.md`, `docs/Decisions.md` перед работой. ТЗ — в проекте claude.ai «батя» (REI_Master_Spec_v3).
- Бизнес-логика только в `packages/core` (чистый TS, без Cloudflare API). `apps/api` — ввод/вывод. Без дублирования формул.
- Финансовые числа считает только код. Деньги — целые минимальные единицы (центы), ставки — доли.
- Никаких крупных порталов (Immobiliare, Idealista, ImmoScout и т.п.), никакого обхода защит, капч, robots.txt.
- Тестовые данные помечаются `is_test = 1` и никогда не выдаются за реальные.
- Секреты только в GitHub/Cloudflare secrets.
- Мелкие осмысленные коммиты (владелец ревьюит по коммитам). Тесты зелёные перед коммитом: `pnpm test && pnpm typecheck`.
- Roadmap: отмечать ✅ только проверенное.
- Документация и интерфейс — на русском; код и комментарии — на английском.
