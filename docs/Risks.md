# REI — Риски и ограничения

| # | Риск | Вероятность / влияние | Мера |
|---|---|---|---|
| R1 | **Правовой статус сбора с сайтов агентств.** Условия сайтов, право ЕС на базы данных (sui generis): массовое извлечение «существенной части» базы может нарушать права. | средняя / высокое | Только после аудита и ручного одобрения; robots.txt; низкая частота; храним только нужные поля и ссылку на оригинал; источник с запретом → `forbidden`. Предпочтение — фидам, полученным с согласия агентства. Не юридическая консультация — спорные случаи решает владелец. |
| R2 | **Антибот-защиты и блокировки IP Cloudflare.** | высокая / среднее | Не обходим. Источник с капчей/челленджем помечается `forbidden` автоматически. |
| R3 | **Лимиты free tier** (10 мс CPU, 50 subrequests, 10k операций очередей, 100k записей D1 в сутки) — общие с ботом LIGURIA LIFE. | средняя / среднее | Потоковый разбор, пишем только изменения, бюджет операций очереди, метрики потребления на странице статуса. Выход — Workers Paid ~5 $/мес по решению владельца. |
| R4 | **Gemini free tier**: дневные лимиты могут меняться; Google может использовать данные бесплатного тарифа для обучения. | высокая / низкое | Бюджет и кэш; приложение работает без ИИ; в ИИ не отправляем личные документы и данные пользователя — только публичные объявления. |
| R5 | **Устаревшие налоговые/юридические данные.** | высокая / высокое | Каждое правило с источником, датой проверки, статусом; непроверенное → низкая уверенность в расчёте и предупреждение. |
| R6 | **Ложная точность оценок.** Цены предложений ≠ сделки; мало аналогов. | высокая / высокое | Диапазоны, а не точки; явная уверенность и причины; OMI/DVF как официальная база; прогноз — не гарантия. |
| R7 | **Поломка адаптеров** при изменении сайтов. | высокая / среднее | `source_health`, журнал ошибок, уведомление владельцу, универсальные адаптеры (JSON-LD) вместо хрупких. |
| R8 | **Ошибки дедупликации.** | средняя / среднее | Автослияние только при высокой вероятности; остальное — ручная проверка; слияние обратимо. |
| R9 | **Фото — ссылки.** После снятия объявления фото пропадают. | высокая / низкое | Анализ фото пока объявление активно, результаты сохраняются. |
| R10 | **Зависимость от аккаунта бати** (Cloudflare, Google). | низкая / высокое | Деплой из GitHub воспроизводим; ежедневный экспорт D1 в артефакты GitHub. |
| R11 | **Условия использования Portale delle Vendite Pubbliche и других аукционов.** | средняя / среднее | Проверить до подключения; при необходимости — только ссылки и ручной импорт. |
| R12 | **Качество OSM-данных об агентствах** — неполные. | высокая / низкое | Ручное добавление источников. |
| R13 | **Финансовый совет.** Платформа даёт расчёты, а не инвестиционные рекомендации. | — | Дисклеймер в интерфейсе и отчётах. |

## Требует решения владельца (по мере появления)
- Подключение конкретных источников (кнопка «одобрить»).
- Переход на платный тариф при упоре в лимиты.
