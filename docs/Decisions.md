# REI — принятые решения

Отклонения от REI_Master_Spec_v3 из-за требования «всё бесплатно». Копия — в проекте «батя» (REI/Decisions.md).

## 24.11.2026 — с владельцем
- Хостинг: Cloudflare Workers Free на аккаунте бати; код — `Kraxzi/rei`, деплой через GitHub Actions (секреты `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `GEMINI_API_KEY` заведены).
- AI: Gemini, отдельный ключ в отдельном Google-проекте.
- Клиент: PWA для Android, без Google Play. Telegram — опционально.
- Крупные порталы не используются вообще (ни скрапинг, ни email-алерты, ни «поделиться»).
- Источники: аукционы, госимущество, банковские объекты, сайты/фиды агентств (автопоиск через OSM → автоаудит → ручное одобрение), фото табличек.
- R2 не используем — фото только ссылками. Домена нет — почта не принимается.
- Первый регион — Лигурия. Приоритетные типы объектов — решим к этапу 2 (ядро поддерживает все).

## 24.11.2026 — архитектурные (принял разработчик)
- TypeScript везде (вместо Python): один язык для Worker и PWA, бесплатный хостинг.
- D1 вместо PostgreSQL/PostGIS; гео — bbox + geohash в SQL, точные проверки в коде.
- Hono в Worker; React + Vite для PWA; статика PWA отдаётся тем же Worker (Workers Static Assets) — один деплой.
- Авторизация — passkeys (WebAuthn): вход отпечатком, это же MFA; паролей нет. Первый вход — по одноразовому коду `BOOTSTRAP_CODE`.
- Деньги — целые центы; ставки — доли; IRR — Ньютон с откатом на бисекцию.
- Cloudflare переименовал права токенов (сент. 2026): токен создан с Workers: Admin, D1/Pages/Queues/KV: Edit, Account Settings: Read.

## 24.11.2026 — источники (с владельцем)
- Вариант Б: при сохранении поиска REI сам ищет агентства в выбранных регионах/провинциях (OSM/Overpass) и проверяет их сайты; подключение — только после одобрения человеком (кнопка «Подключить все подходящие» или по одному). Сайты с жёстким запретом (robots, антибот, запрет в условиях) одобрить нельзя.
- Регион без выбранных провинций сканируется целиком; если регионы не выбраны (вся страна) — поиск агентств не запускается.
