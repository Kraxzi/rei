## Этап 1. Рабочее ядро — 🟨
1. ✅ Монорепо (pnpm workspaces), TypeScript strict, vitest, CI на GitHub Actions.
2. ✅ `packages/core`: таксономия (7 категорий, 69 типов), гео-функции, финансовый движок (общие формулы + модели категорий + сценарии), 45 тестов, в т.ч. эталонные значения.
3. ✅ `apps/api`: Worker + Hono, миграции D1 (вся схема), сиды: 5 стран, 20 регионов Италии + провинции Лигурии, таксономия. Города — этап 2 (ISTAT).
4. ✅ API: страны/регионы/города, таксономия, поисковые профили (CRUD, изоляция по пользователю, audit log), калькулятор `/api/calc`. 13 тестов на реальном SQL.
5. ⬜ Авторизация passkeys + сессии + audit log.
6. ⬜ PWA: каркас, установка, вход, профили поиска, справочники.
7. ✅ Деплой через GitHub Actions в Cloudflare (создание D1, миграции, деплой, smoke-тест): https://rei.serhiy-labunskyy.workers.dev

Приёмка: приложение открывается на телефоне, ставится на рабочий стол, вход по отпечатку, можно создать профиль поиска; тесты зелёные.
